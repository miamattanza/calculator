Финансы — история версий (учёт доходов и расходов, PWA для iPhone)
==================================================================

Версия 1.2 (текущая)
--------------------
- Настройка «Раздельная история» (Настройки → Отображение):
    • Включено: в окне «Расходы» показываются только расходы, а в окне
      «Доходы» — только доходы.
    • Выключено: история доходов и расходов отображается вместе в одном окне.
- Поиск по истории операций с фильтрами:
    • по тексту (заметка или название категории);
    • по категории;
    • по диапазону дат (с / по);
    • по диапазону сумм (от / до).
  Результаты можно открыть для редактирования прямо из поиска.
- В разделе «О приложении» показывается номер версии.

Версия 1.1
----------
- Экран «Обзор» разделён на два окна с переключением свайпом:
    • «Расходы» (синее) — главное число — сумма расходов;
    • «Доходы» (зелёное) — главное число — сумма доходов.
  Ниже — встречный поток и общий баланс, снизу индикатор активного окна.
- Новый способ ввода суммы: свайп вверх по карточке (или кнопка «+»)
  открывает цифровую клавиатуру (1–9, ⌫, 0, ✓). После подтверждения —
  выбор категории. Тип операции берётся из активного окна.

Версия 1.0
----------
- Первая версия PWA-приложения учёта доходов и расходов в стиле iOS.
- Операции с категориями: добавление, редактирование, удаление.
- Мультивалютность: основная валюта для итогов и своя валюта у операции
  с курсом пересчёта.
- Аналитика: кольцевая диаграмма по категориям и помесячная динамика.
- Бюджеты и лимиты по категориям с прогрессом и предупреждениями.
- Прогноз остатка к выбранной дате по плановым платежам и по средним тратам.
- Экспорт/импорт данных (JSON — полная копия, CSV — операции).
- Смена языка (русский/английский) и темы (системная/светлая/тёмная).
- Офлайн-режим и установка на домашний экран (PWA).
