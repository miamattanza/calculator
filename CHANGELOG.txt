Финансы — история версий (учёт доходов и расходов, PWA для iPhone)
==================================================================

Версия 1.13 (текущая) — сигнал лимита, конвертер, свайп-строки
-------------------------------------------------------------
- Аналитика: вместо «Всё время» — «Выбранный период» с полями даты начала и
  конца.
- Сигнал лимита в шапке: круг-индикатор между окном и балансом — оранжевый
  при 80%, красный при 90%, бордовый пульсирующий при превышении; тап ведёт
  в «Бюджеты», где можно отключить уведомление до конца месяца.
- Планирование: если на балансе уже хватает — вместо «мало данных» пишем
  «можно купить сейчас» и сколько останется после покупки.
- Настройки: конвертер валют к основной (ручные курсы + обновление онлайн).
- История: свайп больше не открывает окно — выдвигается сама строка: вправо —
  поле комментария, влево — кнопка удаления; долгое нажатие/тап — изменить.
- Выровнена высота поля даты в форме редактирования.

Версия 1.12 — жесты и правки
----------------------------
- Фоновый паттерн теперь строго позади кнопок/карточек (заливки сделаны
  непрозрачными), а не просвечивает сквозь них.
- Загруженный фоновый рисунок можно удалить (крестик на плитке «свой рисунок»).
- Из редактора категорий убран выбор цвета (цвет назначается автоматически).
- Свайп между «Расходы»/«Доходы» больше не зациклен (на краю — возврат).
- Долгое нажатие на категорию → всплывающий выбор валюты для неё (рядом с
  категорией); у категории появляется бейдж валюты, операции по ней пишутся
  в этой валюте.
- Жесты по строке истории: свайп вправо — комментарий, влево — удалить,
  долгое нажатие (или тап) — изменить (сумма/категория/дата).

Версия 1.11.1 — критический фикс
--------------------------------
- Исправлен «белый экран» (виден только гамбургер) у существующих установок:
  при добавлении раздела «Планирование» не была повышена версия базы данных,
  из-за чего у уже установленного приложения отсутствовало хранилище goals и
  запуск падал. Версия БД повышена (создаётся автоматически при обновлении);
  добавлена устойчивость к отсутствующим хранилищам. Данные не теряются.

Версия 1.11 — Планирование и Бюджеты
------------------------------------
- Формула прогноза утверждена: средний дневной поток = (все доходы − все
  расходы) ÷ число дней ведения учёта; при < 30 дней данных — предупреждение
  «мало данных». Учитываются и плановые доходы (зарплата).
- Новый раздел «Планирование»: вводите сумму и что хотите купить → примерная
  дата накопления по тренду + справка «в среднем в месяц» и по займу.
- Бюджеты переработаны: общий месячный лимит с предупреждением о превышении;
  переключатель «Детализировать лимит» включает лимиты по категориям.

Версия 1.10 — правки UX
-----------------------
- Баланс в шапке — в рамке с подписью «Баланс».
- ДОХОДЫ/РАСХОДЫ — заглавными буквами.
- Цвет вводимой суммы — по окну: расходы синие, доходы зелёные (включая 0).
- Все ячейки категорий одинакового размера (в т.ч. пустые «+»).
- Цвет категории заметнее выделяет иконку; превью в редакторе обновляется.
- В настройках «Оформление» перед «Основная валюта».
- Фоновые паттерны сделаны выразительнее.
- Ручная тёмная тема: выбор цвета фона (пресеты + RGB + яркость).
- «Подгонять историю под экран» показывает минимум 5 последних (без пустоты).
- Прогноз остатка теперь учитывает тренд трат/доходов (не стоит на месте);
  «оценка по средним тратам» убрана — только прогноз.
- Загрузка своей иконки принимает любое изображение (в т.ч. с iPhone) —
  исправлена установка.

Версия 1.9 — правки UX
----------------------
- Категории листаются плавной каруселью (без пробела между страницами).
- Всегда 2 ряда категорий: пустые ячейки «+» открывают добавление категории;
  при >16 категориях появляются дополнительные страницы.
- Переключатель «Подгонять историю под экран» снова работает на «Обзоре»:
  ВКЛ — сколько строк помещается; ВЫКЛ — до «Максимум строк» с прокруткой.
- «Удалить все данные» теперь спрашивает, что удалить, с опцией
  «Сохранить категории».
- В редакторе категории можно загрузить свою иконку из галереи (PNG/JPG/WEBP
  до 3 МБ; изображение обрезается и уменьшается до 64×64 — безопасно).
- Развёрнутую историю (и другие листы) можно закрыть свайпом вниз.
- Отключён двойной тап-зум iOS при быстром наборе цифр.
- В настройках — выбор фонового паттерна (7 вариантов) или своего рисунка.
- Тёмная тема стала тёплой: тёмно-коричнево-оливковая, мягкая, с охровыми
  нотками, невысокий контраст (вместо чистого чёрного).

Версия 1.8 — Фаза 2: быстрый ввод
---------------------------------
- «Обзор» переделан под ввод в 2 касания: на экране сразу табло суммы и
  клавиатура, ниже — категории. Набрал число → тап по категории = запись
  сразу попадает в историю. Кнопка «+» убрана.
- Категории показываются по 8 на страницу; страницы листаются свайпом внутри
  зоны категорий (переключение Расходы/Доходы при этом не срабатывает).
- Часто/недавно используемые категории поднимаются вперёд.
- Баланс вынесен компактной строкой в шапку; там же иконка Аналитики.
- Свайп смены окна Расходы/Доходы работает по всему экрану.
- Внизу — мини-история последних операций с переходом к полной истории/поиску.

Версия 1.7.1 — фикс переводов
-----------------------------
- Имена стандартных категорий теперь тоже переводятся (Продукты, Кафе,
  Транспорт и т.д.) на все 6 языков. Для существующих установок имена
  проставляются автоматически. Переименованные вручную категории остаются
  с пользовательским именем.

Версия 1.7 — Фаза 1: языки
--------------------------
- Добавлены языки интерфейса: русский, английский, итальянский,
  индонезийский, испанский и арабский. Переведены все пункты.
- Для арабского включается режим письма справа налево (RTL).
- При первом запуске показывается экран выбора языка; язык также меняется
  в Настройках.

Версия 1.6
----------
- Число строк истории теперь считается по фактической геометрии экрана
  (реальное положение кнопки «+» и видимая область), с пересчётом после
  первой отрисовки и при изменении размера/ориентации. Исправляет случай,
  когда на телефоне показывалась лишь одна строка.
- Свайп между окнами «Расходы» и «Доходы» работает по всему экрану, страница
  двигается вслед за пальцем и плавно сменяется (эффект как в Instagram).
- Названия «РАСХОДЫ»/«ДОХОДЫ» вынесены из карточки в шапку рядом с меню-
  гамбургером и окрашены в цвет сектора: доходы — зелёный, расходы — синий.
- Поиск упрощён: строка поиска фильтрует список вживую, не открывая
  дополнительные окна. Фильтры (категория, даты, суммы) скрыты за квадратной
  кнопкой с иконкой фильтра справа от строки поиска и раскрываются по нажатию.

Версия 1.5
----------
- В настройках добавлен переключатель «Подгонять историю под экран»,
  управляющий поведением из версии 1.4:
    • Включено (по умолчанию): история подгоняется под размер экрана, снизу
      кнопка «Развернуть историю».
    • Выключено: список с прокруткой и строкой поиска (как в версии 1.3),
      ограниченный числом строк, с кнопкой «Показать всю историю».
- Когда подгонка под экран выключена, в настройках появляется поле
  «Максимум строк» (по умолчанию 10) — сколько операций показывать до кнопки
  «Показать всю историю».

Версия 1.4
----------
- На экране «Обзор» история операций ограничивается по высоте: показывается
  ровно столько строк, сколько помещается на экране без прокрутки.
- Поиск больше не показывается постоянно. Если история не помещается целиком,
  под последней строкой появляется небольшая кнопка «Развернуть историю»
  с числом операций.
- Кнопка открывает историю на весь экран со строкой поиска и фильтрами
  (по тексту, категории, диапазону дат и сумм). В развёрнутом виде история
  ограничена типом активного окна (расходы или доходы) при включённой
  раздельной истории.

Версия 1.3
----------
- Навигация переработана: нижний таб-бар убран, разделы Аналитика, Прогноз,
  Бюджеты, Настройки и Обзор перенесены во всплывающее меню (☰) в верхнем
  левом углу. В меню показаны все пять разделов с иконками.
- Убрана надпись «Финансы» в шапке приложения.
- Номер версии вынесен в самый низ экрана «Настройки».

Версия 1.2
----------
- Настройка «Раздельная история» (Настройки → Отображение):
    • Включено: в окне «Расходы» показываются только расходы, а в окне
      «Доходы» — только доходы.
    • Выключено: история доходов и расходов отображается вместе в одном окне.
- Поиск по истории операций с фильтрами:
    • по тексту (заметка или название категории);
    • по категории;
    • по диапазону дат (с / по);
    • по диапазону сумм (от / до).
  Результаты можно открыть для редактирования прямо из поиска.
- В разделе «О приложении» показывается номер версии.

Версия 1.1
----------
- Экран «Обзор» разделён на два окна с переключением свайпом:
    • «Расходы» (синее) — главное число — сумма расходов;
    • «Доходы» (зелёное) — главное число — сумма доходов.
  Ниже — встречный поток и общий баланс, снизу индикатор активного окна.
- Новый способ ввода суммы: свайп вверх по карточке (или кнопка «+»)
  открывает цифровую клавиатуру (1–9, ⌫, 0, ✓). После подтверждения —
  выбор категории. Тип операции берётся из активного окна.

Версия 1.0
----------
- Первая версия PWA-приложения учёта доходов и расходов в стиле iOS.
- Операции с категориями: добавление, редактирование, удаление.
- Мультивалютность: основная валюта для итогов и своя валюта у операции
  с курсом пересчёта.
- Аналитика: кольцевая диаграмма по категориям и помесячная динамика.
- Бюджеты и лимиты по категориям с прогрессом и предупреждениями.
- Прогноз остатка к выбранной дате по плановым платежам и по средним тратам.
- Экспорт/импорт данных (JSON — полная копия, CSV — операции).
- Смена языка (русский/английский) и темы (системная/светлая/тёмная).
- Офлайн-режим и установка на домашний экран (PWA).
